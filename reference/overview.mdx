## Existing integrations

Use the legacy reference as a starting point for integrations already agreed with Nimbo. Its coverage has been retained while captured examples were removed. Some imported definitions do not include complete response schemas or error cases.

The legacy and preview sections can describe related resources without being interchangeable. Continue using your agreed contract until Nimbo confirms a change for your integration.

## New integrations

Start with your use case and confirm which endpoints are supported. The [public contract preview](/reference/public-preview) helps you inspect parameters and response shapes before that discussion.

## Request execution

This site provides reference pages without an interactive request runner. Use the environment and credentials supplied for your integration in your own development tools.
