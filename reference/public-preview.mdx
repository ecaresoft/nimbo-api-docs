The preview covers public catalog, SAT catalog, Sites, and public portal read contracts. Each endpoint page describes parameters, response shapes, and documented errors from a fixed API revision.

<Note>
  A contract in this preview is not a promise of availability on your API host. Confirm support with Nimbo before building against it.
</Note>

Patient-portal authentication and protected patient records are outside this public preview. Their internal contracts are not included in this site's generated specification.

You can download the [public OpenAPI specification](/openapi/nimbo_public.yml). The document's `x-nimbo-source` field identifies its source revision and artifact digest, so you can distinguish this snapshot from a later update.

For an existing integration, read [Reference scope](/reference/overview) before comparing the preview with the legacy API.
